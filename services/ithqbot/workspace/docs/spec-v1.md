# thqbot 产品需求文档 v1

## 1. 背景

团队需要把 AI 能力接入内部系统，但现有工具彼此割裂：对话在一个系统、文件处理在另一个系统、
任务编排又依赖人工。我们希望交付一个统一入口。

## 2. 目标

- 提供 Web 端对话入口，支持多轮上下文。
- 支持调用技能（skills）完成具体任务。
- 消息链路可横向扩展，重启不丢消息。

## 3. 范围

### 3.1 包含

- 单点登录与会话管理。
- 会话列表与消息记录。
- 技能调用（文本类技能优先）。

### 3.2 不包含

- 移动端原生应用。
- 计费与配额。

## 4. 技术方案

- 前端：React 单页应用，通过 HTTP 接口获取消息。
- 后端：无状态服务，负责鉴权、会话与消息存储。
- 消息骨干：Kafka 解耦接入与执行。
- 存储：Redis 保存运行时状态，关系数据存 PostgreSQL。

## 5. 交互

1. 用户登录后进入会话列表。
2. 选择会话，输入消息并发送。
3. 系统异步执行，前端定时拉取最新消息。
4. 执行结果写入会话记录。

## 6. 指标

- 单条消息端到端延迟低于 10 秒。
- 消息不丢失。
